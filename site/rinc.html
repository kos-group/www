Cómo funciona

Tú subes las facturas. RINC hace el resto.

  1. Carga tus facturas

    El sistema las clasifica y prepara para el proceso.

  2. Avisamos al deudor

    Cartas certificadas con todos los requisitos formales.

  3. Presentamos ante la AEAT

    Modificación de la base imponible, lista para presentar.

  4. Sigue cada expediente

    Panel en tiempo real y avisos en cada fase.
